Futaba Test Radio

Drives a Futaba receiver (FASST, FASSTest, S-FHSS) from this page, with a Sonoff ZBDongle-P USB stick, and shows its telemetry. For bench tests: servos and sensors, no model to fly. Recording a transmitter instead? Use the sniffer page.

This browser can't talk to USB serial ports

Open this page in Chrome, Edge or Firefox 151 or newer on a computer (Windows, macOS or Linux). Phones and Safari don't work.

1Plug in the stick

Plug the Sonoff ZBDongle-P (CC2652P) into a USB port, then pick it in the list (CP2102N USB to UART, or a COM port on Windows).

2Load the radio firmware

Replaces what is on the stick (Zigbee, or the sniffer) with the test radio, about 20 seconds. Skip it if the page says the radio is already there. The sniffer page loads the sniffer back; Sonoff's web flasher puts Zigbee back.

3System and receiver

Props off, motors unplugged. The stick sends as long as this page runs and the tab is open. Stop (or closing the page) cuts the signal: the receiver goes to its failsafe, so set one (step 5) if an ESC is connected.

4Channels

±100 % = 1020..2020 µs, centre 1520 µs (Futaba). Double-click a slider to centre it. Channels 9-16 stay centred.

5Failsafe

What the receiver does when the signal is lost. Sent to the receiver every second while running (FASST 7ch: CH3 only). A FASST receiver forgets it when switched off.

All channels hold their last position.
