FASST Sniffer

Records what a Futaba FASST transmitter sends, with a Sonoff ZBDongle-P USB stick. Nothing to install: this page talks to the stick directly.

This browser can't talk to USB serial ports

Open this page in Chrome, Edge or Firefox 151 or newer on a computer (Windows, macOS or Linux). Phones and Safari don't work.

1Plug in the stick

Plug the Sonoff ZBDongle-P (the "Plus" with a P: CC2652P) into a USB port, then pick it in the list (CP2102N USB to UART, or a COM port on Windows).

Windows doesn't list it?

Windows normally installs the driver by itself after a minute. If it doesn't, install Silicon Labs' CP210x driver and plug the stick in again. Close any other program that uses it (Zigbee2MQTT, Home Assistant, a terminal).

2Load the sniffer

This replaces the stick's Zigbee firmware with the sniffer (about 20 seconds). Skip it if the page says the sniffer is already there.

3About your transmitter

Keep the transmitter about 1 m from the stick. Don't use a "range check" mode unless a step asks for it.

4Record

Do the steps in order. Each one records for a fixed time; you can stop early or redo one. The counters should move while the transmitter is on.

    5Save and send

    Saves all recordings in one text file. Send it to whoever asked you for it.
