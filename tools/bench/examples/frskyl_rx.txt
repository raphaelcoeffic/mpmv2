# MPM CC2500 receiving 60 bytes of a FrSky L chip stream (CC2652:
# cc2652_frskyl.txt, then "txp 20000 50 <17 bytes>"): FrSky L registers on top
# of the frskyx preset, with a 16 bit sync word taken from the stream (here the
# start of the first payload bits of 4e...), fixed length 60 + status.
# RXOFF_MODE RX (0x17 0x0C): the CC2500 syncs again at the next match in the
# same stream, so "rx 62" reads consecutive chunks. PKTLEN is hex (0x3c)
preset frskyx
w 0x0B 0x0A
w 0x10 0x5C
w 0x11 0x3B
w 0x13 0x03
w 0x15 0x47
w 0x12 0x02
w 0x08 0x00
w 0x06 0x3c
w 0x07 0x04
w 0x17 0x0C
w 0x04 0xde
w 0x05 0x25
ch 0
s 0x36
s 0x33
rx 62
